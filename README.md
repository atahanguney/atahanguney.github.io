# atahanguney.github.io

Personal site of **Atahan Güney** (Atahan Guney), 3rd-year electrical & electronics engineering student at Antalya Bilim University.

Live: **https://atahanguney.github.io/**

- `index.html`: the whole site, one static page with no build step and no framework. Fonts come from Google Fonts with system fallbacks.
- `assets/`: SerialScope screenshot (WebP + JPEG) and `og.png`, the social preview image (1200×630).
- `robots.txt` and `sitemap.xml`: this repo controls the domain root, so its `robots.txt` also points to the ElectroField sitemap.
- Structured data: `Person` (with `alternateName` "Atahan Guney" and `sameAs` GitHub and LinkedIn), `ProfilePage`, `WebSite`, and the two projects linked to the person by `@id`.

Projects: [ElectroField](https://atahanguney.github.io/ElectroField/) · [SerialScope](https://github.com/atahanguney/SerialScope)
